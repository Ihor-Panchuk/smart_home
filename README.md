# Smart Home

Учебный full-stack проект для управления домашними устройствами через веб-интерфейс и REST API.

Проект создан для практики Python, FastAPI, PostgreSQL, объектно-ориентированного программирования и веб-разработки.

## Возможности

* Регистрация пользователей и вход в систему.
* Авторизация с помощью JWT.
* Разделение устройств по пользователям.
* Создание, просмотр и удаление устройств.
* Изменение названий устройств.
* Включение и выключение устройств.
* Управление яркостью освещения.
* Изменение температуры термостатов.
* Блокировка и разблокировка дверных замков.
* Получение устройств по типу и состоянию.
* Валидация входных данных.

## Используемые технологии

* **Python** — основная логика приложения.
* **FastAPI** — создание REST API.
* **PostgreSQL** — хранение пользователей и устройств.
* **Psycopg** — подключение к PostgreSQL.
* **Pydantic** — проверка входных данных.
* **JWT** — авторизация пользователей.
* **HTML, CSS, JavaScript** — веб-интерфейс.
* **Git и GitHub** — контроль версий и хранение кода.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Ihor-Panchuk/smart_home.git
cd smart_home
```

### 2. Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создай файл `.env` в корневой папке проекта и укажи параметры подключения к PostgreSQL и секретный ключ JWT:

```env
DATABASE_URL=your_database_url
JWT_SECRET_KEY=your_secret_key
```

Замени примеры реальными значениями для своей среды. Не публикуй пароли и секретные ключи на GitHub.

### 5. Запуск сервера

```bash
uvicorn main:app --reload
```

После запуска документация API Swagger будет доступна по адресу:

http://127.0.0.1:8000/docs

Для работы приложения необходима настроенная база PostgreSQL с таблицами пользователей и устройств.
