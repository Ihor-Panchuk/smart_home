# Smart Home

Учебный full-stack проект для управления домашними устройствами.

Проект создан для практики Python, FastAPI, PostgreSQL, работы с REST API и создания веб-интерфейса.

## Используемые технологии

* Python
* FastAPI
* PostgreSQL
* Psycopg
* Pydantic
* HTML
* CSS
* JavaScript
* Git
* GitHub

## Возможности

Программа позволяет управлять устройствами, связанными с освещением, отоплением и безопасностью.

Доступны следующие функции:

* добавление устройств;
* удаление устройств;
* включение и выключение устройств;
* управление яркостью освещения;
* изменение температуры термостата;
* блокировка и разблокировка дверного замка;
* получение текущего состояния устройств;
* валидация вводимых данных.

В проекте реализован веб-интерфейс, через который можно управлять устройствами.

## О проекте

Проект выполнен исключительно в учебных целях как дополнительная практика изученных технологий.

В дальнейшем планируется дальнейшее развитие проекта и возможное подключение IoT-устройств, таких как Arduino, ESP32, датчики и контроллеры.
