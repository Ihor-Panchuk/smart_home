# Smart Home

Это учебный проект для управления домашними устройствами.

В проекте используются Python, FastAPI, PostgreSQL и Git. В перспективе также планируется создание веб-интерфейса с использованием HTML, CSS и JavaScript.

Проект позволяет осуществлять дистанционное управление домашними устройствами, работающими на основе бинарных состояний.

Проект выполнен исключительно в учебных целях как дополнительная практика изученных технологий.

В дальнейшем планируется возможность подключения IoT-устройств, таких как Arduino, ESP32, различные датчики, контроллеры и другие совместимые системы.

## Используемые технологии

- Python
- FastAPI
- PostgreSQL
- Psycopg
- Pydantic
- Git
- GitHub

## Возможности
На данном этапе программа позволяет управлять устройствами, связанными с освещением, отоплением и блокировкой.

Программа предоставляет возможность:

- включать и выключать устройства;
- управлять яркостью освещения;
- изменять температуру;
- блокировать и разблокировать дверные замки;
- получать текущее состояние устройств.

В перспективе будут добавляться новые возможности и дорабатываться существующие.
